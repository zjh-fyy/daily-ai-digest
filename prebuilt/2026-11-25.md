## 🔥 三、GitHub 开源项目寻宝

### 📈 今日飙升榜

### 1. [Ebony-Vinyl/dsh-our-free-model](https://github.com/Ebony-Vinyl/dsh-our-free-model) 🌟 本月 +48,193 / 86,056 Stars | JavaScript

已经在用 dsh、又想试试不同模型，可以看看这个插件。它把上游网关的免费模型放进同一个选择器，并标出当前网络下哪些能用，省得挨个注册和填密钥。项目宣传「不限量」，但 README 也写了上游会按出口 IP 限额；请求会发往上游，私有代码先别往里贴。最新 macOS 安装包是社区构建，下载前记得看清发布页。

### 2. [pingdotgg/t3code](https://github.com/pingdotgg/t3code) 🌟 本月 +47,147 / 77,494 Stars | TypeScript

如果你在电脑上开着 Claude Code 或 Codex，离开工位后还想看看它跑到哪一步，T3 Code 可以把会话同步到手机上，顺手审批下一步。它调用的是你电脑上已经配置好的编程助手，沿用原有账号和订阅。桌面端有 Windows、macOS 和 Linux 安装方式，也有手机客户端；榜单里列出的最新构建是 nightly，日常用可以优先选正式渠道。

### 3. [pbakaus/impeccable](https://github.com/pbakaus/impeccable) 🌟 本月 +30,688 / 116,301 Stars | Rust

给编程助手一句「把这页做得好看点」，它很容易交回一套熟悉的模板。Impeccable 把这种模糊要求拆成可执行的设计指令：你可以只让它改定价卡片，也可以请它点评整页，指出排版和视觉层级的问题。支持的环境还能在助手修改界面文件时自动检查，把问题赶在交付前指出来。它主要给做网页的人用，通过命令行或编辑器插件接入，没有独立桌面安装包。

### 🏆 高分口碑榜

### 🏆 1. [TheAlgorithms/Python](https://github.com/TheAlgorithms/Python) ⭐ 226,433 Stars | Python

想弄懂排序、搜索这些算法怎么跑，翻这个仓库比只背复杂度表直观。它把不同算法写成可以逐行读的 Python 示例：遇到一道题，先自己做一遍，再对照源码看别人的思路，很适合自学和面试复习。网页上就能查目录、读代码，想动手再用本地 Python 跑。项目也说得很实在：示例以教学为主，真要写业务代码，先看看标准库有没有现成实现。

### 🏆 2. [localsend/localsend](https://github.com/localsend/localsend) ⭐ 100,662 Stars | Dart

手机里有一段大视频想传到电脑，或者想在不同品牌的设备之间发照片，可以试试 LocalSend。两台设备在同一个局域网里就能直传，文件不用先上传到网盘，断开互联网也能用。新版 v1.19.0 给 Fedora 等发行版加了 RPM 安装包，也能用快捷键接受或拒绝传输。常见桌面和手机平台都有客户端；应用本身不会自动更新，优先从应用商店或包管理器安装更省心。
