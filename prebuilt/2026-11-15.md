### 1. [louislam/uptime-kuma](https://github.com/louislam/uptime-kuma) 🌟 今日 +432 / 总 94,082 | JavaScript
- **📌 一句话说清**：这是一个装在自己电脑或服务器上的“网站与软件在线管家”，可以每 20 秒检查一次你搭建的服务是否正常运行，一旦掉线就马上发消息通知你。
- **💡 打个比方**：就像你在家里装了一个 24 小时值班的烟雾报警器，家里哪个服务断网了或者崩溃了，它立刻就会往你手机上发一条警报，不用等到自己打开才发现打不开。
- **🎬 能怎么用**：
  1. 定时监控网页、网盘接口、端口连通性以及 Docker 容器（可以理解成把软件打包独立运行的隔离小盒子）是否还在正常工作。
  2. 支持通过 Telegram、Discord、Slack、邮件等超过 90 种渠道发送掉线提醒，还能生成多语言的状态页和网络延迟折线图。
- **🚪 上手门槛**：「需要跟着教程敲几行命令」。项目虽然支持在 Windows 10 及以上系统运行，但最新发布的 `2.5.11` 版本没有提供现成的 Windows 安装包，需要通过 Docker 或命令行方式来部署。
- **⚠️ 要注意**：
  - 最近的发布版本里没有 Windows 安装包，不能直接双击安装包运行。
