## 🔥 板块三：GitHub 开源项目寻宝

### 📈 今日飙升榜

### 1. [kajisho5/ffmpeg-skill](https://github.com/kajisho5/ffmpeg-skill) 🌟 本周 +3,048 / 11,111 Stars | Python

想把一段横屏访谈剪成竖屏短片，可以让 Claude Code、Cursor 或 Codex 调这套工具来裁画面、加字幕、调音量，导出后再检查时长和分辨率。它把 FFmpeg 的 42 项操作封装成助手能调用的工具，其中 12 项标为稳定。剪辑在本机完成，不用云端账号或 API 密钥；目前没有桌面安装包，通常走命令行。想从语音自动生成字幕，还得另装本地语音识别引擎。

### 2. [ag-ui-protocol/ag-ui](https://github.com/ag-ui-protocol/ag-ui) 🌟 本周 +1,421 / 21,720 Stars | TypeScript

如果你在做一个带 AI 助手的网页，通常得自己接好这些细节：回答怎么边生成边显示，工具跑到哪一步，什么时候该停下来让用户确认。AG-UI 给这些交互定了一套统一的事件格式，同一个助手接网页、手机端或 Slack 时，前端可以复用这套接法。现在 1.0 规范已稳定，有 TypeScript、Python 和 .NET SDK（开发工具包），主要面向写应用的开发者。

### 3. [ChromeDevTools/chrome-devtools-mcp](https://github.com/ChromeDevTools/chrome-devtools-mcp) 🌟 本周 +1,203 / 59,355 Stars | TypeScript

网页突然变慢，或者按钮一点就报错，可以让编程助手打开页面，自己看控制台报错、网络请求和性能记录，还能截图核对实际渲染效果。省下的是来回复制日志、描述页面长什么样的时间。新版还支持让新开的标签页留在后台，调试时少被抢焦点。它主要给做网页的人用，需要 Chrome，再通过编程助手插件、MCP（工具连接接口）或命令行接入。
